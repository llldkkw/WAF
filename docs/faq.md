# 常见问题

### 正常用户被拦截了（误报）怎么办？

1. 面板 → 攻击日志，找到这条记录，点开详情。
2. 点「这是误报」，选择命中的规则，**建议填写路径前缀**（只在该路径下关闭规则），添加后 2 秒内生效。
3. 新站点建议先用「观察模式」跑几天，把误报都处理完再切到「拦截模式」。

### 把自己挡在外面了怎么办？

SSH 登录服务器（通过 VPN 或云厂商控制台），执行：

```bash
sudo -u waf WAF_CONFIG=/etc/waf/waf.yaml waf ip allow 你的IP -note 应急
```

白名单优先级最高，2 秒内生效。

### 忘记密码 / 手机丢失？

另一个管理员在「用户管理」中点「重置凭据」；或在服务器上执行：

```bash
sudo -u waf WAF_CONFIG=/etc/waf/waf.yaml waf user reset -name admin
```

### 攻击地图是空的 / 地区策略不生效？

需要下载 MaxMind GeoLite2 数据库（免费注册），在配置文件中设置 `geoip_db` 后重启。按省份、城市匹配需要 **City** 版；面板的站点编辑页会提示当前数据库是否支持。

### 地区策略「仅允许中国」，我自己出国就进不去了？

内网和 VPN 地址始终放行，连上 WireGuard 后访问不受地区限制。也可以把自己的 IP 加入白名单。

### 人机验证用内置、Turnstile 还是 reCAPTCHA？

- **内置**：不依赖任何第三方，访客无需操作，隐私最好，国内外都能访问。挡住脚本和普通爬虫足够。
- **Cloudflare Turnstile**：免费，大多数访客无需点击；判断是否机器人更准确（Cloudflare 的风险数据）。中国大陆访问速度视网络而定。
- **Google reCAPTCHA**：v2 需要勾选复选框，v3 无感评分；默认经 recaptcha.net 加载，国内可用。

建议平时用「仅可疑访问 + 内置」，遭受攻击时切换到「所有访问」，需要更强识别时用 Turnstile。

### 人机验证会影响搜索引擎收录吗？

会。搜索引擎爬虫不执行 JavaScript，开启「所有访问」后无法收录。需要 SEO 的网站请用「仅可疑访问」，或只在遭受 CC 攻击时临时开启「所有访问」。API、Webhook 等非浏览器路径请加入「免验证路径」。

### 推送里的一键链接点不开？

- 需要在配置中设置 `admin.public_url`。
- 链接指向 VPN 内的面板地址，手机需要先连上 WireGuard。
- 每个链接只能用一次，7 天后过期。

### Oracle Cloud 邮件发送失败？

- 发件人必须是 Email Delivery 中的「已批准发件人」。
- 用户名是 SMTP 凭据的长字符串（`ocid1.user...` 开头），不是登录邮箱。
- 端口 587 + STARTTLS；SMTP 端点要与 Approved Sender 所在区域一致。
- 新账号默认有发送配额，超出会被拒绝。

### HTTPS 打不开 / 证书错误？

面板总览会列出「没有可用证书」的 HTTPS 域名。解决方法任选其一：

- 在「证书管理」上传覆盖该域名的证书（含泛域名）；
- 在配置中启用 `acme`，并确保该域名已解析到网关、80 端口可从公网访问。

### 能保护 SSH、数据库等非 HTTP 服务吗？

WAF 只检查 HTTP/HTTPS。其他服务按 README 的方式通过 nftables 只对 VPN 开放，再加上 WireGuard，就是「跳板」的访问方式。

### 性能如何？

单个 Go 进程，规则编译结果按配置缓存复用。测试环境中，配置一个站点时进程内存约 25 MB；每增加一种不同的防护配置，会多占用一份编译后的规则。实际延迟和吞吐取决于请求大小、防护等级（PL）和机器配置，**上线前建议先用观察模式和自己的真实流量验证**。
